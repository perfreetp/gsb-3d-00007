# 3D 智能工厂流水线仿真系统

基于 **Vue 3 + TypeScript + Three.js + Vite** 的 3D 智能工厂流水线仿真。

## 功能

- **双输送带**：输送带 A（加工线，→）与输送带 B（质检线，←），皮带纹理实时滚动。
- **加工设备**：产品进入后下压加工，带状态灯与加工倒计时。
- **两台机械臂**（平面两连杆逆解 + 腰关节 + 夹爪）：
  - **R1（橙色）**：在 A 线末端完成「抓取 → 抬升 → 旋转 90° → 跨越搬运 → 反向旋转 → 放置」到 B 线。
  - **R2（蓝色）**：在分拣点抓取不良品，旋转 180° 后放入**异常品区**料箱。
- **检测工位**：扫描光束左右扫掠，检出后产品按良/不良显示绿色/红色发光环。
- **良品区 / 异常品区**：良品流向 B 线末端良品料箱，不良品被 R2 分拣；料箱按 3×3 分层码放，满位自动回收。
- **实时面板**：总产量、良品/不良数量、良率、仿真时间、六台设备的运行状态与实时事件日志。
- **交互控制**：暂停/继续、复位、0.5x–4x 仿真倍速、0–60% 不良品概率调节；OrbitControls 旋转/平移/缩放。

## 工艺流程

```
上料 → 输送带A → 加工设备 → R1 抓取/旋转/搬运放置 → 输送带B(反向)
     → 质检工位 → 分拣点
                   ├─ 良品 → 良品区
                   └─ 不良品 → R2 抓取/旋转 → 异常品区
```

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 类型检查 + 生产构建
npm run preview  # 预览构建产物
```

## 目录结构

```
src/
  sim/
    config.ts       布局与工艺参数
    types.ts        数据类型
    scene.ts        渲染器/相机/灯光/地面/区域标识
    conveyor.ts     输送带（滚动皮带、支架、辊筒）
    product.ts      产品模型与良/不良外观
    robot.ts        机械臂（IK、任务队列、夹爪、TCP 法兰）
    stations.ts     加工设备、质检工位、料箱
    simulation.ts   核心编排：产品流、闸门、机器人作业、统计与事件
  components/
    FactoryViewer.vue  3D 视图与 OrbitControls
    Dashboard.vue      KPI / 设备状态 / 事件日志
    ControlBar.vue     控制条
  App.vue
```
