# 3D 智能工厂流水线仿真系统

基于 **Vue 3 + TypeScript + Three.js** 实现的数字孪生工厂仿真：产品在两条输送带间依次经历
上料 → 加工 → 机械臂搬运 → 视觉质检 → 良品入库 / 不良品分拣，全部流程实时三维可视化。

## 功能特性

- **3D 产线场景**：双输送带（皮带纹理滚动动画）、加工冲压设备、视觉质检龙门、六工位场景与中文悬浮标签。
- **四自由度机械臂**：底座回转 + 肩部 + 肘部 + 腕部滚动，实时两连杆逆运动学（IK）解算，腕部始终保持垂直。
- **完整工艺动作**：机械臂完成「下降 → 抓取 → 抬升 → 转运并 180° 旋转 → 对位 → 放置」全流程。
- **随机质检分拣**：按可配置概率生成不良品，质检工位扫描判定后，机械臂优先把不良品分拣进红色异常品箱，良品码垛到绿色成品托盘（2×2×2）。
- **实时数据看板**：总产量、合格品、不良品、良率百分比、运行时长。
- **设备状态监控**：输送带 A/B、加工设备、机械臂、质检工位的待机 / 运行 / 异常分拣状态灯。
- **交互控制**：暂停/继续、手动上料、重置产线、仿真速度（0.3–3x）、不良品概率（0–60%）滑块。
- **实时事件日志**：加工、质检结果、分拣、入库等事件滚动推送。
- 鼠标左键旋转、右键平移、滚轮缩放（OrbitControls），PCF 软阴影、雾效与霓虹工业风 UI。

## 技术栈

- Vue 3（Composition API + `<script setup>`）、TypeScript 严格模式
- Three.js 0.169（WebGLRenderer、阴影、灯光、程序化几何体与 Canvas 贴图）
- Vite 5 构建

## 快速开始

```bash
npm install
npm run dev      # 开发模式，默认 http://localhost:5173
npm run build    # 类型检查 + 生产构建（输出 dist/）
npm run preview  # 预览生产构建
```

## 工艺与调度说明

- 产品每约 3.6 秒自动上线一件（可手动补料），在输送带 A 依次排队经过加工设备（冲压动画 + 橙色加工标记）。
- 加工完成的产品到达搬运位后，机械臂将其抓取并旋转 180° 放置到输送带 B 起点。
- 产品在 B 线经过质检工位扫描：良品点亮绿色标记继续前行，由机械臂码垛到成品托盘；不良品点亮红色标记并在分拣位停止，机械臂优先将其投入异常品箱（伴随红色警报灯与质检工位告警状态）。
- 良率 = 合格品 /（合格品 + 不良品），在产品完成分拣/入库时实时累计。
